실제로도 맞는지 궁금했다.

성과가 좋은 프로젝트는 아니다. 대신 예측이 왜 틀리는지, 어떤 구조가 과적합을 줄이는지 직접 확인한 경험이 이후 다른 ML 프로젝트를 볼 때 기준이 됐다.

즉각적 검증 루프 — 며칠 안에 모델 예측이 실제 시장에서 맞는지 확인할 수 있다.

전 스택 학습 압축 — 데이터 수집·피처·ML·자동화·인프라를 한 프로젝트에서.

03 · LEARNING JOURNEY 4 PHASES · 2 YEARS

매매 시스템을 4번 바꿨다.

지표 → ML → 하이브리드. 각 단계가 어디서 막혔고 다음 단계로 무엇을 시도했는지.

PHASE 01
2022

단순 지표 매매

RSI 과매도 + MACD 골든크로스. 가장 직관적인 진입 조건부터 시작했다.
→ 백테스트 성능은 높았지만 실전에서는 False Positive가 60%를 넘었다. 지표만으로는 신호 품질을 보장할 수 없었다.
PHASE 02
2022 — 2023

멀티 지표 필터링

볼린저·거래량·전고점 돌파 조합으로 신호 품질을 올렸다. 규칙을 늘려 보완.
→ 상승장과 횡보장이 바뀌면 규칙 성능이 바로 무너졌다. 정적 규칙만으로는 시장 변화를 따라가기 어려웠다.
PHASE 03
2023 — 2024

ML 도입 + LLM 보조

XGBoost 첫 도입. 훈련 88%에 들떠 실전 투입 → 51%(동전 던지기). 과적합 충격.
→ SMOTE, depth=4, 앙상블을 적용하며 과적합을 줄였다. ML 단독 역시 바로 실전에 쓰기엔 불안정했다.
PHASE 04 · NOW
현재

하이브리드 2-Stage 시스템

기술 필터 1차(5개 조건 통과) + ML 앙상블 2차(XGB·LGBM·RF Soft Voting)의 직렬 구조. 둘 중 한쪽만 통과한 신호는 거른다. 한쪽의 약점을 다른 쪽이 덮는다.
→ 지표 단독과 ML 단독 모두 한계가 있었다. 두 단계를 직렬로 묶는 구조가 가장 안정적이었다.

05 · ARCHITECTURE 2-STAGE HYBRID FILTER

기술 필터가 거른 뒤 ML이 한 번 더 본다.

ML 단독은 False Positive가 너무 많고, 지표 단독은 Regime 변화에 무력하다. 두 시스템을 직렬로 쌓아 한쪽의 약점을 다른 쪽이 덮는 구조로 재설계했다.

STAGE 1 · TECHNICAL FILTER

HybridSurgeDetector

500+ USDT 페어를 asyncio로 병렬 스캔. 5가지 멀티 필터를 통과한 종목만 다음 단계로 보낸다.

015분 가격 변화≥ +1%
021시간 가격 변화≥ +3%
03거래량 (vs 40봉 평균)≥ 1.2×
04RSI 모멘텀 구간50 — 95
05하이브리드 스코어≥ 0.25
STAGE 2 · ML ENSEMBLE

MLPredictor (Soft Voting)

100+ 피처 → SelectKBest로 Top 50 → 3개 모델의 평균 확률. 임계값 0.25를 넘은 신호만 매수 실행.

M1XGBoost (n_est=300, depth=4)P(↑)
M2LightGBM (Leaf-wise)P(↑)
M3RandomForest (배깅)P(↑)
→Soft Voting · 평균 확률≥ 0.25
✓두 단계 모두 통과 → 매수EXECUTE

07 · ML ENSEMBLE 3-MODEL · SMOTE · DEPTH-4

앙상블은 한 모델의 약점을 덮는다.

XGBoost는 비선형 패턴을, LightGBM은 대용량 피처를, RandomForest는 과적합을 억제한다. 세 모델의 평균 확률이 0.25를 넘을 때만 매수 신호로 인정한다.

MODELPARAMSROLE
XGBoost depth=4 · n_est=300 비선형 순차 앙상블
LightGBM leaf-wise 대용량 피처 빠른 학습
RandomForest parallel bagging 과적합 억제 · 분산 감소
SMOTE · 급등 이벤트 5–10% (희귀) → k_neighbors=5로 합성 샘플 생성 → 1:1 균형화
scale_pos_weight=5 · 양성 클래스 가중 강화
결정적 교훈
OVERFIT — DEPTH MATTERS
훈련 88%,
실전 51%.
max_depth=7 깊은 트리는 노이즈까지 학습했다. max_depth=4로 제한하자 일반화 성능이 더 안정됐다.
TARGET LABEL
미래 6봉 (= 30분) 내 +3% 이상 상승 여부를 이진 분류.
단일 봉 방향이 아니라 실제 수익 구간에 가까운 패턴을 학습
SCALER
RobustScaler — 이상치(spike)에 강건한 정규화.
중앙값·IQR 기반 → spike에 휘둘리지 않음
