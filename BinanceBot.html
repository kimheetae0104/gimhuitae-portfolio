02 · PROBLEM WHY HYBRID

백테스트 80%,
실전에선 51%.

암호화폐 시계열은 금융 데이터 중에서도 노이즈가 극단적이다. 규칙 기반 매매도, ML 단독 매매도 결국 같은 벽에 부딪혔다 — 학습 곡선과 실전 곡선의 괴리.

XGBoost를 처음 도입했을 때, 훈련 정확도 88%를 보고 실전에 투입했다. 실전 정확도는 51%였다. 동전 던지기와 같았다.

"지표는 거짓 신호를 만든다.
ML은 노이즈를 외운다."

둘을 따로 쓰면 둘 다 진다. 둘을 직렬로 쌓아야 신호 품질이 살아난다 — 그게 이 프로젝트의 출발점이었다.

시장 노이즈 — 8 BARS

↑ 7 봉의 노이즈 속에 1 봉의 진짜 급등.
False Positive 60%를 줄이는 것이 모델의 핵심 목표였다.

SCAN MARKET  500+ pairs
BARS / SCAN  200 × 5m
SURGE RATE  5–10%

03 · ARCHITECTURE 2-STAGE HYBRID FILTER

기술 분석이 통과시킨 신호만,
ML 앙상블이 한 번 더 본다.

ML 단독은 False Positive가 너무 많고, 지표 단독은 Regime 변화에 무력하다. 두 시스템을 직렬로 쌓아 한쪽의 약점을 다른 쪽이 덮는 구조로 재설계했다.

STAGE 1 · TECHNICAL FILTER

HybridSurgeDetector

500+ USDT 페어를 asyncio로 병렬 스캔. 5가지 멀티 필터를 통과한 종목만 다음 단계로 보낸다.

01 5분 가격 변화≥ +1%
02 1시간 가격 변화≥ +3%
03 거래량 (vs 40봉 평균)≥ 1.2×
04 RSI 모멘텀 구간50 — 95
05 하이브리드 스코어≥ 0.25
STAGE 2 · ML ENSEMBLE

MLPredictor (Soft Voting)

100+ 피처 → SelectKBest로 Top 50 → 3개 모델의 평균 확률. 임계값 0.25를 넘은 신호만 매수 실행.

M1 XGBoost (n_est=300, depth=4)P(↑)
M2 LightGBM (Leaf-wise)P(↑)
M3 RandomForest (배깅)P(↑)
→ Soft Voting · 평균 확률≥ 0.25
✓ 두 단계 모두 통과 → 매수EXECUTE

05 · ML ENSEMBLE 3-MODEL · SMOTE · DEPTH-4

앙상블은
한 모델의 약점을 덮는다.

XGBoost는 비선형 패턴을, LightGBM은 대용량 피처를, RandomForest는 과적합을 억제한다. 세 모델의 평균 확률이 0.25를 넘을 때만 매수 신호로 인정한다.

MODELPARAMSROLE
XGBoost depth=4 · n_est=300 비선형 순차 앙상블
LightGBM leaf-wise 대용량 피처 빠른 학습
RandomForest parallel bagging 과적합 억제 · 분산 감소
SMOTE · 급등 이벤트 5–10% (희귀) → k_neighbors=5로 합성 샘플 생성 → 1:1 균형화
scale_pos_weight=5 · 양성 클래스 가중 강화
결정적 교훈
OVERFIT — DEPTH MATTERS
훈련 88%,
실전 51%.
max_depth=7 깊은 트리는 노이즈까지 외웠다. max_depth=4로 제한하자 일반화 성능이 살아났다.
TARGET LABEL
미래 6봉 (= 30분) 내 +3% 이상 상승 여부를 이진 분류.
단봉 예측이 아닌 "수익 구간"을 학습 → 의미 있는 신호만 캡처
SCALER
RobustScaler — 이상치(spike)에 강건한 정규화.
중앙값·IQR 기반 → spike에 휘둘리지 않음
