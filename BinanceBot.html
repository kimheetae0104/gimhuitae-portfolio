# 신호 생성 로직 (의사코드)
def detect_signal(df):
  prob = ensemble_predict(df)
  
  cond = (
    (df['rsi'] < 35)
    & (df['vol_ratio'] >= 2.5)
    & (df['macd_hist'] > 0)
    & (prob >= 0.83)
  )
  
  if cond.any():
    send_alert(
      symbol=df[cond]['symbol'],
      prob=prob[cond]
    )

Binance ML Bot What I Learned
실전 운용 후 발견한 것

시장은 모델보다 빠르게 변한다

01
시장 노이즈 — 백테스트와 라이브의 괴리
백테스트 F1 0.73 → 라이브 F1 0.51 수준으로 하락. 학습 기간 외 시장 레짐 변화가 주요 원인. 워크포워드 검증의 중요성을 직접 체감.
02
과적합의 유혹 — 피처가 많을수록 위험
20개 이상 피처 추가 시 트레이닝셋 성능은 올라가지만 OOT 성능이 하락. 피처 중요도 기반 pruning으로 핵심 8개로 압축하는 것이 실전에서 더 안정적.
03
앙상블이 주는 안정감 — 단일 모델 대비 분산 감소
XGBoost 단독은 급격한 시세 변동 구간에서 오신호율이 높았으나, LightGBM 소프트 보팅 합산 후 오신호 12% 감소. 다양성 확보의 실질적 효과 확인.
04
자동화의 한계 — 리스크 관리는 별개의 문제
신호 탐지 정확도와 실제 수익률은 다른 축. 포지션 사이징·손절 로직 없이는 좋은 신호도 손실로 이어질 수 있음을 실전 운용으로 직접 경험.
