02 · PROBLEM WHY THIS MATTERS
코일 10개 중 4개는
소둔 후에 예외 공정으로 빠진다.
그 60%는 소둔 투입 전에 포착된다.

계획된 정규 Skinpass와 달리, 비계획 Skinpass는 소둔 완료 후 품질 검사에서 표면·형상·재질이 기준에 미달한 코일에 대해 긴급 투입되는 예외 공정이다. 수집된 데이터 기준 전체 코일의 40.8%에서 비계획이 발생하고 있으며, 이는 설비 가동률 저하, 납기 지연, 에너지 추가 소비, 물류 비용 증가를 동시에 유발한다.

04 · 4 HYPOTHESES ALL ACCEPTED

가설 4개를 먼저 세우고,
그 논리를 바탕으로 모델 구조에 적용해봤다.

H1 · 재질등급
재질등급 C가 구조적 비계획 발생 신호인가?
✓ Kruskal-Wallis p < 0.001
→ Material Gate 1차 조건
H2 · 항복강도
항복강도·강종이 발생 위험 구조를 만드는가?
✓ 강종 차이 p < 0.001
→ Material Gate 2차 조건
H3 · 형상×표면
형상·표면 복합이 비선형 급증을 일으키는가?
✓ 복합 구간 +24%p
→ surface_shape_composite
H4 · 강종×등급
강종과 재질등급의 교호작용이 핵심인가?
✓ F1 +0.031 향상
→ grade_steel_interaction
가설 검증 결과 시각화 (H1~H4)

H1~H4 가설 기반 파생변수 4개가 SHAP 중요도 상위 8개 이내에 모두 포함됐다. 공정위험복합·품질위험점수가 1·2위.

STAGE 1 · MATERIAL QUALITY GATE

명백한 고위험은
규칙으로 즉시 차단

IF 재질등급 == C
OR 항복강도 ≥ 임계값
→ 고위험 분류
H1 + H2 검증 결과를 결합한 하드 필터.
Gate=1 → 담당자 경보 발령.
