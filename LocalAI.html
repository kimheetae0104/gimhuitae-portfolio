컨텍스트 주입
현재 열린 노트 내용이 자동으로 프롬프트에 들어간다. 따로 복붙하지 않아도 지금 작업 중인 맥락 위에서 바로 답을 받게 했다.
2
로컬 추론
Ollama가 Gemma 4를 로컬에서 돌린다. 네트워크 요청 없이 평균 2.1초 안에 응답이 돌아오는지 실제 작업 흐름에서 확인했다.
3
노트 저장
AI 응답을 다시 노트 안으로 넣어 지식 관리 흐름을 끊지 않게 했다. 대화가 따로 흩어지지 않고 모든 흔적이 로컬 노트에 남는다.

Local AI Agent What I Learned
로컬 모델의 현실

좋은 점보다 먼저
어디서 한계가 드러나는지 확인했다

01
긴 컨텍스트의 약점
2000 토큰이 넘는 노트를 그대로 넣으면 응답 품질이 급격히 떨어졌다. "로컬이라서 다 된다"가 아니라, 긴 노트는 결국 청킹과 전처리가 필요하다는 현실을 확인했다.
02
한국어 품질 격차
영어보다 한국어 응답 품질이 눈에 띄게 약했다. 그래서 모델 선택에서도 "가볍게 잘 도는가"만이 아니라 "내 언어에서 실제로 쓸 만한가"를 같이 봐야 한다고 느꼈다.
03
그래도 얻은 것 — 실용적 실험 정신
완벽한 대체재를 만든 건 아니지만, 어디까지는 로컬만으로 충분하고 어디부터는 타협이 필요한지 몸으로 익혔다. 클라우드 의존 없이 AI 도구를 조립하는 감각을 얻었다.
04
작은 모델, 명확한 태스크
범용 질문보다 "이 노트의 요점을 3줄로 정리해줘" 같은 명확한 태스크에서 Gemma 4 모델도 충분히 유용하다. 모델 크기보다 태스크 설계가 더 중요.
