# Portfolio UI Kit

A high-fidelity recreation of Heetae Kim's portfolio site. Mostly cosmetic — buttons don't really submit, but the navigation between Home → Work index → Case study → About → Contact works.

## Files
- `index.html` — interactive shell, switches screens via simple state
- `Header.jsx`, `Footer.jsx` — chrome
- `HomeScreen.jsx` — hero + selected work + writing strip
- `WorkIndex.jsx` — full work archive table
- `CaseStudy.jsx` — single project page
- `AboutScreen.jsx` — bio + résumé table
- `ContactScreen.jsx` — short form
- `ProjectTile.jsx`, `Marquee.jsx`, `Button.jsx` — primitives

Reads `../../colors_and_type.css` for tokens.
