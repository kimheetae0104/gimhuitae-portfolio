> **작성자**: 김희태

## 한 줄 요약

냉연 코일 4,000건의 물류·품질 실적을 기반으로, 소둔 공정 이후 발생하는 **비계획 Skinpass(예외 공정)의 발생 위험을 사전 예측**하는 모델을 개발. **현장 가설(H1~H4)을 모델 구조에 직접 녹여낸 2단계 판별 시스템(Material Quality Gate + 로지스틱 회귀)** 으로, 비교군 6개 모델 중 가장 높은 Recall(0.595)을 달성한 품질 리스크 예측 프로젝트.

---

## 1. 프로젝트 배경

Skinpass(조질압연)는 소둔 처리 후 코일에 1~3%의 미세 압하량을 적용하는 최종 품질 결정 공정이다. 계획된 정규 Skinpass와 달리, **비계획 Skinpass**는 소둔 완료 후 품질 검사에서 표면·형상·재질이 기준에 미달한 코일에 대해 긴급 투입되는 예외 공정이다.

수집된 데이터 기준 **전체 코일의 40.8%에서 비계획이 발생**하고 있으며, 이는 설비 가동률 저하, 납기 지연, 에너지 추가 소비, 물류 비용 증가를 동시에 유발한다. 더 큰 문제는 현장 판단 기준이 담당자마다 달라 일관성이 흔들린다는 점이었다.

| 비용 항목 | 영향 |
|----------|------|
| 리드타임 증가 (소둔→Skinpass→재검사 평균 4~8시간 추가) | 건당 생산 지연 |
| 직접 처리 비용 (설비 가동비 + 에너지 + 인건비) | 정규 대비 비용 상승 |
| 생산 계획 차질 | 연쇄 납기 지연 |
| 납기 지연 위험 | 고객 신뢰도 저하 |
| 반복 처리로 인한 물성 저하 | 폐기 손실 |

## 2. 프로젝트 목표

발생 여부를 맞히는 데 그치지 않고, **"왜 이 코일에서 비계획이 나오는가"** 를 가설로 먼저 설명하고 그 논리를 모델 구조에 녹여내는 것을 핵심 목표로 설정.

| 구분 | 내용 |
|------|------|
| 분석 대상 | 냉연 코일 4,000건 (코일번호 C000001~C004000) |
| 입력 변수 | 원천 13개 + 가설 기반 파생 10개 (총 22개) |
| 분석 방법 | EDA → 가설 수립·검증 → 피처 설계 → 데이터 증강 → 모델링 → SHAP 해석 |
| 평가 지표 | **Recall** (미탐지 비용 우선) + F1, AUROC 보조 |
| 주요 도구 | Python 3.9 · scikit-learn · LightGBM · imbalanced-learn · SHAP |

## 3. 데이터 구조

| 변수명 | 유형 | 분포 | 도메인 의미 | 타겟 상관 |
|--------|------|------|-----------|----------|
| 강종 | 범주형 4종 | DP590/IF강/SPCC/SPFH440 | 강종별 소둔 반응 차이 | 범주형 |
| 두께(mm) | 연속형 | 0.40~2.30 | 박물재 형상 제어 난이도 | +0.016 |
| 항복강도(MPa) | 연속형 | 표면조도와 r=0.48 | 저강도→항복점 연신 위험 | **−0.081** |
| 형상불량지수 | 순서형 | 0~5 | 0=정상, 5=심각 | **+0.074** |
| 재질등급 | 순서형 | A>B>C 균등 | C등급 발생률 48.8% | 범주형 |
| 압연하중편차율(%) | 연속형 | 평균≈0 | 하중 불균일→형상 왜곡 | −0.006 |
| 이전공정경과시간(h) | 연속형 | 2~72 | **유의성 없음(p=0.208)** | −0.020 |

**클래스 분포**: 미발생 59.2% / 발생 40.8% — 완전 불균형은 아니나 단순 Accuracy로 평가 불가.

## 4. EDA 핵심 발견

### 강종별·재질등급별 발생률

- **강종별**: SPCC(47.9%) · IF강(43.3%) > 평균(40.8%) > DP590(34.7%)
  - 연질강(SPCC, IF강)은 소둔 후 항복점 신장(Lüders Band)이 발생하기 쉬워 Skinpass가 구조적으로 더 자주 필요
- **재질등급별**: A=36.3%, B=37.1%, **C=48.8%** (C vs A: 12.5%p 차이)
- **항복강도와 표면조도**: r=0.48 (고강도 → 소둔로 표면 산화 증가)

### EDA 종합 결론

1. 비계획 발생의 핵심 신호는 **재질등급과 항복강도**에 집중
2. 단일 변수의 선형 효과보다 **변수 간 교호작용**이 더 강한 예측 신호 제공
3. 이전공정경과시간은 발생·미발생 분포 차이가 거의 없어 예측력 제한

## 5. 가설 수립 및 검증 (4개 가설 모두 채택)

가설 수립 → 통계 검증 → 파생변수 설계 → 모델 구조 반영의 일관된 흐름을 유지.

| 가설 | 핵심 질문 | 검증 결과 | 모델 반영 |
|------|----------|----------|----------|
| **H1** | 재질등급 C = 구조적 비계획 발생? | ✅ 채택 (Kruskal-Wallis p<0.001) | Material Gate 1차 조건 |
| **H2** | 항복강도·강종 = 발생 위험 구조? | ✅ 채택 (강종 차이 p<0.001) | Material Gate 2차 조건 |
| **H3** | 형상×표면 복합 = 비선형 급증? | ✅ 채택 (복합 구간 +24%p) | 복합 파생변수로 입력 |
| **H4** | 강종×재질등급 = 핵심 교호작용? | ✅ 채택 (F1 +0.031 향상) | 교호작용 파생변수 설계 |

**핵심 인사이트**: 비계획 Skinpass 발생은 단일 변수가 아닌, **재질등급 → 항복강도 → 형상·표면 복합 → 강종 교호작용**의 계층적 구조로 작동.

---

## 6. 피처 엔지니어링 — Material Quality Gate + 가설 기반 파생변수

### 6-1. Material Quality Gate (1단계 규칙 기반 판별)

H1·H2 검증 결과를 결합하여, 현장 운영자의 "명백한 고위험 조건" 판단 논리를 데이터로 정식화한 하드 필터.

```
material_quality_gate = 1   IF (재질등급 == C) OR (항복강도 ≥ 임계값)
material_quality_gate = 0   OTHERWISE

→ Gate = 1 : 즉시 "고위험 코일" 분류 → 담당자 경보 발령
→ Gate = 0 : 2단계 확률 모델로 세부 위험도 추정
```

### 6-2. 가설 기반 파생변수 10종 (요약)

| 파생변수 | 근거 | 산출 방식 | SHAP 기여 |
|---------|------|---------|----------|
| `is_grade_high_risk` | H1 | 재질등급 == C → 1 | 상위권 |
| `hardness_strength_gate` | H2 | 항복강도 ≥ 기준 → 1 | 상위권 |
| `surface_shape_composite` | H3 | 형상불량 × (Ra/평균Ra) | 상위권 |
| `grade_steel_interaction` | H4 | grade_risk × (강종_enc+1) | 상위권 |
| `quality_risk_score` | H1+H2 | grade_risk × (항복강도/평균) | **최상위권** |
| `process_risk_composite` | 공정 | \|압연하중편차\| × (1+\|온도편차\|/50) | **최상위권** |

### 6-3. 제거 변수

- **이전공정경과시간**: 독립표본 t-검정 p=0.208 → 최종 모델 입력에서 제거

## 8. 모델링 — 6개 모델 비교

3가지 역할로 구분된 모델 전략으로 가설 기반 설계의 가치를 정량 비교.

| 모델 | Accuracy | Precision | **Recall** | F1 | AUROC | 비고 |
|------|----------|-----------|-----------|-----|-------|------|
| LR (원천변수) | 0.554 | 0.465 | 0.543 | 0.501 | 0.568 | 기준 모델 |
| LR + 파생변수 | 0.551 | 0.472 | 0.466 | 0.469 | 0.587 | AUROC 최고 |
| LightGBM | 0.519 | 0.433 | 0.420 | 0.427 | 0.539 | Baseline |
| XGBoost | 0.513 | 0.430 | 0.407 | 0.416 | 0.521 | Baseline |
| Random Forest | 0.508 | 0.428 | 0.399 | 0.413 | 0.521 | Baseline |
| **★ Material Gate + LR** | **0.531** | **0.413** | **0.595** | **0.487** | **0.508** | **★ Recall 최고 — 최종 선정** |

**선정 근거**: 비계획 코일을 놓치는 비용 > 잘못된 경보 비용 → **Recall 우선 평가**.

**False Negative 비교**: Material Gate + LR 163건 vs LR 원천변수 187건 → **24건 미탐지 감소 효과 확인**.

## 9. 모델 해석 — SHAP 분석

| 순위 | 변수명 | 구분 | 해석 |
|------|-------|------|------|
| **1위** | 공정위험복합 (파생) | ★ H3+공정 | 압연·온도 복합 공정 편차 |
| **2위** | 품질위험점수 (파생) | ★ H1+H2 | 소재 화학·기계 복합 위험도 |
| 3위 | 항복강도(MPa) | 원천 | 고강도 소재 소둔 교정 한계 (H2 지지) |
| 4위 | 압연하중편차율 | 원천 | 하중 불균일 → 형상 왜곡 |
| 5위 | 재질등급 | 원천 | C등급 위험 (H1 직접 효과) |
| 7위 | 표면형상복합 (파생) | ★ H3 | 비선형 복합 불량 조건 |
| 8위 | 등급강종교호 (파생) | ★ H4 | 강종 × 등급 교호작용 |

→ **H1~H4 가설 기반 파생변수 4개가 모두 SHAP 상위 8개 이내 포함**. 가설 수립 단계의 도메인 판단이 데이터에 의해 사후 재확인된 정합성을 입증.

## 10. 현장 적용 — 3단계 파일럿 전략

전면 자동화가 아닌, 운영자 신뢰도를 단계적으로 확보하는 점진적 도입.

| 단계 | 명칭 | 운영 방식 | 목표 | 기간 |
|------|------|---------|------|------|
| **1단계** | 경보 시스템 | Material Gate 발동 코일에 소둔 투입 전 자동 경보. 운영자 최종 판단 유지 | 고위험 포착 ≥80% | 1~2개월 |
| **2단계** | 의사결정 지원 | 전 코일 발생 확률 + SHAP 원인 3가지 제시 | 발생률 10% 감소 | 2~4개월 |
| **3단계** | 반자동 제어 | 소둔 파라미터 자동 조정 권고. 운영자 승인 기반 실행 | 발생률 25% 감소 | 4~8개월 |

## 11. 한계 및 개선 방향

- **데이터 한계**: 소둔로 분위기 데이터(N₂/H₂ 비율, 이슬점) 미수집 → 표면조도 예측력 한계의 핵심 원인
- **검사 노이즈**: 비계획 판정에 검사자 육안 판단 개입 → 학습 데이터 구조적 노이즈
- **모델 한계**: AUROC 0.508로 전체 판별력은 제한적 → Gradient Boosting 스태킹 앙상블 검토
- **운영 변동성**: 계절성·신규 강종 도입 시 분포 변화 대응 모니터링 체계 필요

**핵심 개선 방향**: 알고리즘 고도화보다 **데이터 커버리지 확장**이 우선 (소둔로 실시간 온도 프로파일·분위기 가스 정보 MES 연동).

## 12. 핵심 결론 및 배운 점

### 분석이 도달한 결론

> 가설 → 통계 검증 → 모델 설계 → SHAP 사후 검증의 흐름이 처음부터 끝까지 같은 방향을 가리켰다는 것은, 분석 설계 논리가 일관되게 맞아떨어졌음을 의미한다.

### 개인적 배운 점

- **모델 구조 = 현장 판단 순서의 번역**: Material Quality Gate + 확률 모델의 2단계 구조는 현장 운영자가 실제로 코일을 검토하는 사고 흐름(물리적 제약 확인 → 위험도 추정)을 그대로 모델에 반영한 것. 단순 정확도 경쟁이 아닌 **현장 신뢰도 확보**가 모델 설계의 1차 목표가 될 수 있음을 체감.
- **Recall 중심 평가의 의미**: 미탐지 1건의 비용이 오탐지 1건보다 훨씬 큰 도메인에서는, 단일 지표(Accuracy/F1) 기준 최우수 모델이 실무 최우수 모델이 아닐 수 있음을 확인.
- **가설 기반 파생변수의 힘**: SHAP 상위 8개 중 4개가 가설 파생변수 — 도메인 지식을 변수로 변환하는 작업이 단순 부스팅 모델 튜닝보다 더 큰 성능 개선을 가져올 수 있음.
