# Local AI Development Portfolio - Design Spec

**Date:** 2026-04-27  
**Purpose:** 채용 면접/이력서 제출용 로컬 AI 개발 포트폴리오 마크다운 파일  
**Target Audience:** AI/ML 개발자 직무 채용담당자

## 설계 개요

Connect AI Lab 유튜브 채널을 통해 학습한 로컬 AI 개발 경험을 체계적으로 정리한 포트폴리오. Python과 Claude(AI)를 활용하여 Obsidian + Ollama + AntiGravity 통합 시스템을 구현한 내용을 중심으로 작성.

## 포트폴리오 구조

### 1. 개요 (Introduction)
- 로컬 AI 개발에 관심을 가진 배경
- 클라우드 AI 의존성 감소 및 비용절감 목표
- 학습 과정의 핵심 요약

### 2. 학습 경로 (Learning Journey)
- **Connect AI Lab 유튜브 채널 학습**
  - 채널명, 핵심 콘텐츠 소개
  - 학습한 주요 개념 및 기술

### 3. 기술 스택 & 도구
- **Obsidian**: 지식 축적 및 관리
- **Ollama**: 로컬 LLM 실행
- **AntiGravity**: AI 워크플로우 연결
- **Python**: 메인 구현 언어
- **Claude (AI)**: 구현 과정 지원

### 4. 핵심 구현 프로젝트
Obsidian + Ollama + AntiGravity 통합 시스템
- **프로젝트 목표**: 로컬 AI를 활용한 지식 관리 및 자동화 시스템
- **구현 언어**: Python
- **주요 기능**: 로컬 LLM 연동, 워크플로우 자동화
- **결과**: 클라우드 의존성 제거, 비용 절감, 로컬 AI의 실질적 가치 입증

### 5. Connect AI Lab 익스텐션 활용
- GitHub 레포지토리 기반 익스텐션 소개
- 코드 기반 개발 워크플로우
- 로컬 AI 개발의 실질적 이점 및 필요성

### 6. 배운 점 & 인사이트
- 로컬 AI의 발전 가능성
- 엔터프라이즈 환경에서의 활용 가치
- 지속적 학습 및 개선 방향

### 7. 참고 자료
- Connect AI Lab 유튜브 채널 링크
- GitHub 레포지토리 링크

## 작성 원칙

1. **구체성**: 추상적 설명보다는 구체적인 예시와 코드 스니펫 포함
2. **명확성**: 각 섹션의 목적과 학습 내용을 명확하게 표현
3. **채용 친화적**: 채용담당자가 기술 수준을 쉽게 파악할 수 있도록 구성
4. **증거 기반**: GitHub 링크, 유튜브 채널 등 근거 자료 포함
