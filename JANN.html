SwiftUI + Python/CoreML 연결, 오프라인 DB 구조, 3단계 폴백 파이프라인까지 실제 앱 구현 전 과정을 완성한 프로젝트.

LEARNED · CoreML 통합

Python → CoreML → SwiftUI 연결

YOLOv8n을 Python으로 학습한 뒤 CoreML로 변환해 온디바이스 추론을 구현했다. 학습 시간을 161분 → 17분으로 단축하면서 box_loss도 30% 개선됐다.
CHALLENGE · 데이터 품질

외국 식재료 편향 + 용기 내 인식 불가

향미 네트워크 DB가 서양 식재료 중심이라 한국 재료(김치·된장·고추장)의 매핑이 부족했다. 용기에 담긴 식재료 인식의 한계도 확인됐다.
