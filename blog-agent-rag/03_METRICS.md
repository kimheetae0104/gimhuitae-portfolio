# 정량 평가 — 환각률·검증 통과율

⚠️ **솔직한 한계 명시**: 아래 "환각 0건"은 **DART 수치 50%+ 차이** 기준이며, 이는 **수치 환각**만 측정한 부분 지표입니다. 실제 발행 가능한 글 기준에선 시장 구분 오류, 사업 분야 단정, 재무 강점 모순 등 **의미론적 환각**도 발견됐고 v12에서 추가 룰로 보강했습니다.

## 측정 방식

- **테스트 종목**: 매일 +10% 이상 급등 종목 자동 수집 (시장 데이터)
- **버전당 5종목** 작성 후 결과 비교
- **수치 환각** = DART 공식 수치와 50%+ 차이 (자동 감지)
- **구조 모순** = 룰베이스 13+개 (PBR/PER/적자/상한가/EPS음수/시장구분/사업분야/재무강점)
- **의미 환각** (외부 검토 필요): 사업 분야 부정확, 시장 구분, 평가 논리

## 검증 단계별 효과 (5종목 평균)

```
[1차 LLM 출력]
     │
     ▼ 형식 검증
   1.4건 위반 → 재시도
     │
     ▼ 팩트체커
   0.6건 환각 → 재시도
     │
     ▼ 모순 감지 (10+ 룰)
   3.2건 모순 → 재시도
     │
     ▼ (MAX 2회 재시도 후)
   1.2건 잔재
     │
     ▼ 자동 교정 (코드 강제)
   0건 (모두 교정)
     │
     ▼ Gemini 검증 (gemini-2.5-flash-lite, 무료 티어)
   종목 혼동 / 수치 환각(30%+) / 종목코드 정확성 / 사실 창작 / 밸류에이션 모순
   score 0~100점 + critical 플래그
   critical=True → 배포 차단 + Telegram 긴급 알림
     │
     ▼ 후처리 (메타/태그/노이즈)
   [최종 출력]
```

**핵심 인사이트**: LLM은 가이드를 줘도 무시하는 경우가 많음. 룰베이스 검증 + 코드 강제 교정 + Gemini 이중 검증이 LLM 응용의 안정성 핵심.
