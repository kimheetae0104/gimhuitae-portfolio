## [v13] — RAG 7단 + Gemini 무료 검증 + 종목코드 뉴스 (2026-05)

### 추가
- **Obsidian RAG (7번째 RAG 단계)**: 과거 220개 .md 포스트 → nomic-embed-text(Ollama) 임베딩 → ChromaDB 영속 벡터 DB → 섹터 필터 2단계 검색 → 유사 포스트 2개 LLM 프롬프트 주입
- **Gemini 무료 검증 (5번째 검증 단계)**: gemini-2.5-flash-lite (AI Studio 무료 티어). 종목 혼동·수치 환각(30%+)·종목코드·사실 창작·밸류에이션 모순 검출. AI_MODE 무관 자동 활성화
- **4단 폴백 큐**: Gemini 429 쿼터 소진 시 자동 모델 전환 (gemini-2.5-flash-lite → gemini-3.1-flash-lite → gemini-flash-lite-latest → gemini-2.5-flash)
- **종목코드 기반 뉴스 크롤링**: `/item/news.naver?code={code}` 파라미터로 동명이종 혼재 차단. 소스 태그 `naver_finance:{code}` 트레이서빌리티 확보
- **보안 강화**: 하드코딩된 경로·토큰 제거, `.gitignore`, `.env.example` 분리

### 지표
| 항목 | 수치 |
|---|---|
| 수치 환각 | 0/5건 |
| 최종 잔재 | 0건 |
| RAG 단계 | 7단 |
| 검증 단계 | 5중 |
| Gemini 검증 | score 85, pass=True, issues=[] |

### 의사결정
- **왜 Obsidian?** 이미 220개 검증된 포스트가 축적돼 있었음 → 추가 큐레이션 0, "정답 예시" 즉시 활용
- **왜 ChromaDB?** FAISS 대비 메타데이터 필터링(`where={"sector"}`)이 2줄로 끝남, 로컬·무료·영속
- **왜 nomic-embed-text?** Ollama 이미 설치 → 한 줄 추가로 활성화, API 키·비용 없음

## [v12] — 의미론적 환각 3종 룰 추가 (2026-04)

### 추가
- **시장 구분 룰**: DART `corp_cls` 필드로 KOSPI/KOSDAQ 자동 대조 → 오표기 감지
- **사업 분야 환각 룰**: DART 사업보고서에 없는 분야("반도체/엔터/AI")를 본업으로 단정하면 감지
- **재무 강점 모순 룰**: 영업·당기순 적자 + "부채비율·유보율 낮아 안정적" 표현 차단

### 수정
- 외부 검토자가 발견한 E사(바이오) 글 오류 3건을 시스템 룰로 흡수:
  1. 시장 구분 오류 (KOSDAQ → 실제 KOSPI)
  2. 본업 단정 환각 (반도체 장비 → 실제 본업은 의약품+게임)
  3. 재무 강점 모순 (적자 + "안정적" 공존)

### 지표
| 수치 환각 | 의미론적 환각 | RAG 단계 | 검증 단계 |
|---|---|---|---|
| 0/5건 | 0건 (v12 보강 후) | 6단 | 4중 |

### 의사결정
- "환각 0건"을 자기 측정만으로 판단하면 안 된다. 외부 검토자의 즉각 발견 → **자기 측정 기준의 한계를 명시하고 외부 검토를 시스템화**

## [v10] — 자동 교정(_auto_fix_contradictions) 도입 (2026-03)

### 추가
- **`_auto_fix_contradictions()`**: MAX_RETRIES=2 소진 후 잔재를 코드가 결정론적으로 강제 교정
  - 적자 + "안정적" → "본업이 적자 상태로 실적 회복 관찰이 필요합니다"로 치환
  - PBR > 5 + "적정/저평가" → "고평가 구간"으로 치환
  - 영업이익 음수 + 표에 "흑자" → "적자"로 치환
  - 등락률 < 28% + "상한가" → "급등"으로 치환
  - 첫 문장 잘못된 등락률 자동 교정

### 의사결정
- 재시도만 무한 반복하면 비용·시간 폭증 → MAX_RETRIES 상한 설정 후 코드 안전망 도입
- "LLM이 못 한다면 코드가" 원칙 확립

### 지표
| 수치 환각 | 최종 잔재 | 코드 교정 발동 |
|---|---|---|

## [v7] — 룰베이스 모순 감지 도입 (2026-02)

### 추가
- **`_detect_contradictions()`**: 13+ 룰
  - PBR > 5 + "저평가/적정"
  - PER > 50 + "저평가"
  - EPS 음수 + "PER 저평가"
  - 영업·당기순 적자 + "재무 안정적" (변형 포함)
  - 등락률 < 28% + "상한가"
  - 부채 100%+ + "안정적"
  - 유상증자 + "재무 안정성"
  - 영업이익 음수 + 표에 "흑자"
  - 핵심 공시 본문 누락

### 배경
- 시스템 프롬프트에 `PBR < 1 = 저평가` 명시해도 LLM이 무시하는 현상 반복 → 정규식이 더 안정적
