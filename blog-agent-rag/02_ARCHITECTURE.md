## 검증 루프 상세 (LLM 응용의 핵심)

```
                     [LLM 1차 출력]
                          ↓
                  ┌───────────────┐
                  │  형식 검증     │── 위반? ──┐
                  │ (헤딩/분량)    │            │
                  └───────────────┘            │
                          ↓ OK               재시도
                  ┌───────────────┐           │
                  │  팩트체커      │── 환각? ─┤
                  │ (DART 대조)    │           │
                  └───────────────┘            │
                          ↓ OK               (MAX 2회)
                  ┌───────────────┐            │
                  │  모순 감지     │── 모순? ─┤
                  │ (10+ 룰)      │            │
                  └───────────────┘            │
                          ↓ OK                 │
                  ┌───────────────┐            │
                  │  자동 교정     │←──────────┘
                  │ (코드 강제)    │ (재시도 후도 잔재면)
                  └───────────────┘
                          ↓
                  ┌───────────────┐
                  │  후처리        │
                  │ (메타 라벨/    │
                  │  해시태그/     │
                  │  뉴스 노이즈)  │
                  └───────────────┘
                          ↓
                    [최종 출력]
```

## 기술 의사결정 (Why)

| 결정 | 이유 |
|---|---|
| LLM = Gemini Flash | Ollama 로컬은 환각 심함, Claude API 키 없음, Gemini Pro는 무료 한도 0, Flash는 분당 15회 충분 |
| RAG 6단 | "재무 3줄"만 주면 LLM이 빈 곳 환각 → 회사 정보·지분·공시·시황 모두 명시적 주입 |
| 룰 베이스 모순 감지 | LLM에 "PBR 0.49 = 저평가"라고 시켜도 종종 무시 → 정규식이 더 안정적 |
| 자동 교정 (코드 강제) | 재시도해도 같은 모순 반복 → 마지막 안전망 |
| Few-shot 패턴 | 정답글의 인과관계 추적 구조 학습 (단순 시세 나열 → 시장 평가 논리) |
| 시계열 지분 추적 | DART 사업보고서엔 시간순 변동만 있음 → 가장 최신값을 정규식으로 추출 |
| 후처리 정규식 | LLM이 못 고치는 잔재 (메타 라벨, placeholder)는 코드가 정리 |
