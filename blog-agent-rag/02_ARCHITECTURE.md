## 검증 루프 상세 (LLM 응용의 핵심)

```
                     [LLM 1차 출력]
                          ↓
                  ┌───────────────┐
                  │  형식 검증     │── 위반? ──┐
                  │ (헤딩/분량)    │            │
                  └───────────────┘            │
                          ↓ OK               재시도
                  ┌───────────────┐           │
                  │  팩트체커      │── 환각? ─┤
                  │ (DART 대조)    │           │
                  └───────────────┘            │
                          ↓ OK               (MAX 2회)
                  ┌───────────────┐            │
                  │  모순 감지     │── 모순? ─┤
                  │ (10+ 룰)      │            │
                  └───────────────┘            │
                          ↓ OK                 │
                  ┌───────────────┐            │
                  │  자동 교정     │←──────────┘
                  │ (코드 강제)    │ (재시도 후도 잔재면)
                  └───────────────┘
                          ↓
                  ┌───────────────┐
                  │  Gemini 검증   │ ← gemini-2.5-flash-lite (무료 티어)
                  │ (AI_MODE 무관) │   429 소진 시 4단 폴백 큐
                  │ pass/fail/     │── critical? ──→ 배포 차단
                  │ critical/score │               Telegram 긴급 알림
                  └───────────────┘
                          ↓ pass
                  ┌───────────────┐
                  │  후처리        │
                  │ (메타 라벨/    │
                  │  해시태그/     │
                  │  뉴스 노이즈)  │
                  └───────────────┘
                          ↓
                    [최종 출력]
```

## 기술 의사결정 (Why)

| 결정 | 이유 |
|---|---|
| LLM = exaone3.5:7.8b 로컬 (기본) / gemini-2.5-flash 클라우드 | 로컬 우선으로 API 비용 없음, cloud 폴백으로 품질 보장. AI_MODE 환경변수로 전환 |
| Gemini 검증 전용 (gemini-2.5-flash-lite) | AI Studio 무료 티어 — 검증에만 사용, AI_MODE 무관. 429 쿼터 소진 시 4단 폴백 큐 자동 전환. GEMINI_API_KEY 있으면 자동 활성화 |
| RAG 7단 | "재무 3줄"만 주면 LLM이 빈 곳 환각 → 회사 정보·지분·공시·시황·Obsidian 유사 포스트 모두 명시적 주입 |
| Obsidian RAG | 과거 220개 포스트 → 섹터 필터 유사글 검색 → Few-shot 패턴 강화. 단순 임베딩이 아닌 섹터 필터 2단계 검색 |
| 종목코드 기반 뉴스 | 종목명 검색은 동명이종 혼재 → Naver Finance code 파라미터로 정확 매칭. 소스 태깅으로 트레이서빌리티 확보 |
| 룰 베이스 모순 감지 | LLM에 "PBR 0.49 = 저평가"라고 시켜도 종종 무시 → 정규식이 더 안정적 |
| 자동 교정 (코드 강제) | 재시도해도 같은 모순 반복 → 마지막 안전망 |
| Few-shot 패턴 | 정답글의 인과관계 추적 구조 학습 (단순 시세 나열 → 시장 평가 논리) |
| 시계열 지분 추적 | DART 사업보고서엔 시간순 변동만 있음 → 가장 최신값을 정규식으로 추출 |
| 후처리 정규식 | LLM이 못 고치는 잔재 (메타 라벨, placeholder)는 코드가 정리 |
| HTML 파일 미저장 | 블로그 생성 후 HTML 파일 로컬 저장 안 함 — Google Sheets + Obsidian에만 저장 |
