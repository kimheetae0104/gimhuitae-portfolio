LHV — 열풍로 발열량 5분 예측

열풍로 LHV를 5분 주기로 예측하는 모델을 만들고, 전환대기 직후 COG가 과하게 들어가는 구간을 데이터로 찾아낸 프로젝트. 예측 모델보다 낭비 구간 발견이 더 중요한 결과였다.

Overview

열풍로는 연소중 → 축열중 → 전환대기를 반복한다. 목표 LHV는 1,012 kcal/Nm³ (±15). 이 범위를 벗어나면 연료 과잉 소모 또는 선철 품질 저하가 발생한다. LHV가 흔들리면 원가와 품질이 같이 흔들린다.

상관분석 결과 COG 유량(r=+0.49), BFG 유량(r=−0.44)이 주요 제어 변수였다. Dome 온도와 공정 단계는 r≈0으로 예측력이 없었다. 현장 경험칙을 그대로 믿지 않고 데이터로 검증한 것이 출발점이었다.

Process
진행 순서
01
공정 흐름 도식화
어디서 조정하고 어디서 측정되는지 선후관계를 정리. COG와 BFG의 발열량 차이부터 이해해 핵심 변수를 좁혔다.
02
경험칙을 4개 가설로 분해·검증
BFG CO함량, Dome온도, 파생변수, 전환 직후 구간을 각각 따로 검증. 데이터로 판단하는 습관을 만들었다.
03
입력 변수 선별 기준 재설정
상관계수보다 실제로 조정 가능한 변수를 먼저 확인. 혼합가스↔BFG r=0.995 다중공선성 발견으로 혼합가스유량 제거.
04
5개 모델 비교 후 Ridge 채택
복잡한 모델보다 Ridge(α=1)이 Test MAE 11.99로 가장 안정적. COG·BFG 유량과 LHV 사이의 선형 관계가 생각보다 강했다.
05
예측 결과를 운영 기준으로 연결
COG 과잉 투입 구간을 발견해 실제 절감 시나리오로 정리. 모델 성능보다 이 발견이 더 중요했다.
가설 검증 결과
H1 · BFG CO함량 가설
BFG CO함량 1% 증가 → LHV +20 kcal?
✕ 기각 · p = 0.41
실제 영향은 거의 없었다. 성분 변수 하나로 LHV를 설명할 수 없다는 걸 분명히 확인.
H2 · Dome 온도
Dome 온도가 높을수록 LHV가 상승한다?
✕ 기각 · ANOVA p = 0.576
r≈0, F통계량 <1. 오래 쓰이던 지표였지만 원인이 아니라 결과에 더 가까웠다.
H3 · 파생변수
COG/BFG 비율 파생변수가 예측력을 높인다?
△ 부분기각 · R² 동일
원본 COG유량보다 더 잘 설명 못함. 대신 다중공선성 문제를 분명히 드러냈다.
H4 · 전환대기 직후
전환대기 직후 구간에서 COG가 과잉 투입된다?
✓ 채택 → 절감 시나리오
COG효율 0.08457이 연소중 0.08460보다 낮았다. 낭비 구간을 플래그로 바꿔 모델에 직접 넣었다.
