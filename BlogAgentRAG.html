02 · 문제 정의 WHY THIS MATTERS

1개 종목 = 1시간.
LLM에 맡기면 환각.

매일 상한가·급등 종목이 5~15개 발생한다. 시세 수집, 공시 검토, 뉴스 정독, 글 작성, 배포까지 한 종목에 약 1시간. 5개면 하루 절반이 사라진다.

핵심 문제
투자 정보의 환각 = 자본시장법 위반 + 독자 피해.
어떤 형태로든 반드시 막아야 한다.
실제 환각 사례 — 경인전자 (초기 v3)
LLM 출력 (v3)
"경인전자는 엔터테이먼트 산업에서 강점을 가지고 있으며, 매출 1조원으로 전년 대비 50% 성장했습니다."
DART 실제 (v11)
사업: 가전 리모컨·스위치 제조
매출: 229억원 ← 4,259% 차이
LLM 크기 문제가 아니었다.
입력 데이터 자체가 부실했다.

# LLM이 재시도해도 같은 모순 반복 → 코드가 강제 교정
for pat in [
  r"재무\s*지표상의?\s*안정적?\s*흐름[^.\n]*\.?",
  r"안정적인?\s*재무\s*(?:상태|구조)[^.\n]*\.?",
]:
  raw = re.sub(pat, "본업이 적자 상태로 실적 회복 관찰이 필요합니다.", raw)
