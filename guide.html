01
Design Philosophy
✓ 원칙
  • 숫자와 결과로 말한다 — 텍스트보다 지표 강조
  • 여백이 콘텐츠다 — 빽빽하면 신뢰도 하락
  • 포트폴리오 자체가 기술의 증명이다
  • 단일 포인트 컬러 — 파란 액센트 하나만
  • 엔지니어 정체성: 모노스페이스 폰트를 레이블에 사용
  • 반응형 우선 — 모바일에서도 동작
✗ 금지
  • 스킬 퍼센트 바 (Python 90% — 무의미)
  • rainbow 태그 색상 — 단색 중립으로
  • 15개 이상 프로젝트 나열
  • 스톡 이미지, 플레이스홀더
  • 과도한 애니메이션 — 정보 전달 목적만
  • border-radius 과다 사용 — 샤프한 엣지 선호

4px 기반 그리드. 모든 간격은 4의 배수. 토큰: --s-1(4px) ~ --s-11(192px)
--s-1
4px — 아이콘 내부 간격
--s-2
8px — 태그 패딩, 아이콘↔텍스트

12px — 카드 내부 소항목 간격
--s-4
16px — 버튼 패딩, 카드 info 패딩
--s-5
24px — 카드 gap, 태그↔타이틀

--s-7

Motion
호버로 직접 테스트해봐. 애니메이션은 반드시 정보를 전달하거나 상태를 명확히 할 때만 사용.

140ms
BASE
220ms
SLOW
420ms
IN·OUT
420ms
--dur-fast: 140ms — 색상, 테두리 전환 (nav hover, tag hover)
--dur-base: 220ms — 카드 hover (translateY, shadow)
--dur-slow: 420ms — 페이지 진입 fade, 스크롤 애니메이션
--ease-out: cubic-bezier(0.2, 0.7, 0.2, 1) — 대부분의 경우
--ease-in-out: cubic-bezier(0.65, 0, 0.35, 1) — 모달, 전환 효과
