## 권장 사양

- **비율**: 16:10 (예: 800×500)
- **포맷**: PNG (스크린샷) 또는 JPG (사진)
- **용량**: 각 200KB 이하 권장 (페이지 로딩 속도)
- **내용**: 가능한 한 **숫자·결과·UI**가 보이게. "이게 뭐 하는 건지 한 컷에 보이는" 이미지가 가장 강력

## 이미지 없으면

비워두면 현재 색블록 placeholder가 그대로 표시됨. 가짜 이미지보다 빈 자리가 나쁘진 않음.
